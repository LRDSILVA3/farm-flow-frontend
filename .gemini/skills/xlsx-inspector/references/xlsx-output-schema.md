# XLSX Inspector Output Schema

This document explains the structure of the JSON output generated by the `inspect-xlsx.cjs` script.

The script outputs a single JSON object where each key is a sheet name from the inspected workbook.

## Root Object

*   **`<sheetName>` (string):** Each key in the root object corresponds to a sheet in the workbook. The value is an object containing the sheet's data and formulas.

## Sheet Object (`<sheetName>`)

Each sheet object has the following properties:

*   **`data` (array of arrays):** This represents the sheet's data as a 2D array, where each inner array is a row and each element in the inner array is a cell's value.
    *   **Example:**
        ```json
        "data": [
          ["Header 1", "Header 2"],
          ["Value A1", "Value B1"],
          ["Value A2", "Value B2"]
        ]
        ```

*   **`formulas` (array of objects):** This is a list of all the cells in the sheet that contain formulas. Each object in the array has the following properties:
    *   **`cell` (string):** The cell's address (e.g., "A1", "C5").
    *   **`formula` (string):** The formula contained in the cell (e.g., "SUM(A1:B1)").
    *   **Example:**
        ```json
        "formulas": [
          {
            "cell": "C1",
            "formula": "SUM(A1:B1)"
          },
          {
            "cell": "D2",
            "formula": "IF(A2>10, 'High', 'Low')"
          }
        ]
        ```

## Full Example

```json
{
  "Sheet1": {
    "data": [
      ["Category", "Value"],
      ["A", 10],
      ["B", 20],
      ["Total", 30]
    ],
    "formulas": [
      {
        "cell": "B4",
        "formula": "SUM(B2:B3)"
      }
    ]
  },
  "Sheet2": {
    "data": [
      ["Name", "Score"],
      ["Alice", 95],
      ["Bob", 88]
    ],
    "formulas": []
  }
}
```
