# Contexto do Projeto: Farm Flow Frontend

## Visão Geral
Aplicação frontend desenvolvida em React com TypeScript, focada em fluxos de fazenda/agrícolas ("farm-flow"). O projeto utiliza bibliotecas modernas como `date-fns` para manipulação de datas.

## Stack Tecnológica
- **Linguagem:** TypeScript
- **Framework:** React
- **Bibliotecas Identificadas:** date-fns

## Estrutura de Pastas Importante
- `/src/hooks`: Contém lógica reutilizável (ex: `useCounterAnimation.ts`).

## Estado Atual
- O projeto possui código legado com comentários e variáveis em Português.
- Objetivo atual: Refatoração global para Inglês e aplicação de Clean Code.
